# Spring Boot Fundamentals – Employee Directory

A practice project for Spring Boot 3 fundamentals: an `Employee` JPA entity exposed as a REST resource through Spring Data REST, backed by MySQL, with a Spring Security configuration that loads users from the database.

## Tech Stack

- Java 17, Spring Boot 3.1
- Spring Data JPA (Hibernate) + MySQL
- Spring Data REST
- Spring Security (`JdbcUserDetailsManager`)
- Lombok

## Features

- `Employee` entity (`firstName`, `lastName`, `email`) persisted with JPA
- CRUD REST endpoints generated by Spring Data REST at `/members` (paging, sorting, HAL links), default page size 3
- Spring Security setup with role-based rules for `/api/employees/**` and users loaded from a `members` table via JDBC

The security configuration is still a work in progress: the role rules target `/api/employees/**` while the repository is exposed at `/members`, and the authorities query is not set yet.

## Getting Started

### Prerequisites

- JDK 17
- MySQL running locally

### Configuration

Create the database:

```sql
CREATE DATABASE employee_directory;
```

Connection settings are in `src/main/resources/application.properties`:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/employee_directory
spring.datasource.username=${DB_USERNAME:root}
spring.datasource.password=${DB_PASSWORD:root}
```

Set the `DB_USERNAME` and `DB_PASSWORD` environment variables to override the default `root`/`root` credentials. The `employee` table is created automatically (`spring.jpa.hibernate.ddl-auto=update`).

### Run

```bash
git clone https://github.com/Hussein-Fouani/SpringBootFund.git
cd SpringBootFund
./mvnw spring-boot:run
```

The application runs on `http://localhost:8080`.

## API Endpoints (Spring Data REST)

| Method | Path | Description |
|--------|------|-------------|
| GET | `/members?page=0&size=3&sort=id` | List employees (paged) |
| GET | `/members/{id}` | Get an employee |
| POST | `/members` | Create an employee |
| PUT | `/members/{id}` | Replace an employee |
| PATCH | `/members/{id}` | Partially update an employee |
| DELETE | `/members/{id}` | Delete an employee |
